# Maths for Machine Learning and EDA Assignment

## Overview

This project covers fundamental mathematical concepts used in Machine Learning along with Exploratory Data Analysis (EDA) on the California Housing Dataset.

The assignment is divided into four tasks:

1. Derivative and Slope Intuition
2. Gradient Descent Experiment
3. Probability Basics
4. California Housing Dataset EDA

---

## Task 1: Derivative and Slope Intuition

Function Used:

f(x) = x² + 2x + 1

Objectives:

- Compute derivatives numerically.
- Understand slope at different points.
- Visualize the function using a graph.

Observations:

- The graph is an upward-opening parabola.
- Slope increases as x increases.
- Derivative values at x = 1, 3, and 5 are approximately 4, 8, and 12.

---

## Task 2: Gradient Descent Experiment

Function Used:

f(x) = x²

Objectives:

- Implement Gradient Descent.
- Observe convergence toward the minimum value.

Observations:

- x decreases in every iteration.
- The algorithm moves toward the minimum point.
- Gradient Descent converges toward x = 0.

---

## Task 3: Probability Basics

Objectives:

- Simulate 1000 coin tosses.
- Calculate experimental probabilities.

Observations:

- Heads and tails occur almost equally often.
- Experimental probability approaches theoretical probability.
- Probability becomes closer to 0.5 as the number of trials increases.

---

## Task 4: California Housing Dataset EDA

Dataset:

California Housing Dataset from Scikit-Learn.

Analysis Performed:

- Dataset Inspection
- Shape and Column Analysis
- Missing Value Check
- Summary Statistics
- Histogram
- Scatter Plot
- Correlation Heatmap

Observations:

- Dataset contains 20640 records and 9 features.
- No missing values are present.
- House prices are concentrated in lower and middle ranges.
- Median Income has a strong positive relationship with house prices.
- The dataset is suitable for machine learning analysis.
