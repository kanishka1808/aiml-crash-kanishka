# E-Commerce Sales Performance Analysis (EDA Project)

A comprehensive, multi-file Exploratory Data Analysis (EDA) workflow performed on the **Olist Brazilian E-Commerce Public Dataset**. This project analyzes sales performance, customer purchasing behaviors, logistics, and geographical distributions to generate data-driven business insights.
